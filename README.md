# ☕ Coffee Shop Website (Frontend Project)

A modern and responsive **Coffee Shop Website** built using **HTML, CSS, and JavaScript**.  
This is a **frontend-only project** created for learning, practice, and portfolio showcase.

## 🌟 Features

### 🖥️ User Interface
- Clean & modern coffee shop design
- Responsive layout (desktop & mobile friendly)
- Smooth scrolling navigation bar
- Attractive hero section

### ☕ Products
- Coffee product cards with images
- Price display
- Add to Cart button (alert-based)

### ⭐ Testimonials
- Sliding testimonials
- Previous / Next navigation buttons

### 📖 About Us
- Simple description about the coffee shop
- Read More interaction

### 🖼️ Gallery
- Image grid layout
- Click image to open fullscreen modal preview

### 📩 Contact Us
- Contact form with validation
- Success alert on submission
- Social media icons (GitHub, Instagram, Facebook)

### 🔐 Login Page (UI Only)
- Sign In / Sign Up UI
- Animated toggle effect
- Social login icons
- **No backend authentication (UI only)**

---

## 🛠️ Tech Stack

- **HTML5**
- **CSS3**
- **JavaScript (Vanilla)**
- **Google Fonts**
- **Font Awesome**

> ❌ No database
